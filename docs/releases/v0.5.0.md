# Font Design MCP 0.5.0

This release adds reference-driven type design and safer editing, from PR #1.

## Highlights

- **Calibrated visual references:** import bounded PNGs from the workspace inbox with `reference_import`,
  preserve immutable reference evidence, and compare drawings with outlines using `render_glyph` overlays.
- **Explicit design checks:** declare coverage, metric targets, stroke probes, and digit-spacing rules;
  inspect tangent alignment and per-master reports with `font_analyze`.
- **Shared-scale proofs:** compare multiple glyphs and revisions with `render_proof`.
- **Safe curve editing:** preserve adjacent handles when moving nodes, align or mirror cubic handles,
  and declare smooth joins without silently changing their geometry.
- **Linked accents:** opt into anchor-based composition with `compose_accent(auto_align=true)` so later
  edits update accent placement and inherited advances atomically; detach links for local overrides.
- **Optional export gate:** `font_build(require_design_checks=true)` checks the declared design contract
  on every configured master before exporting.
- **Reliable release checks:** development CI validates registry metadata separately from published
  checksums; tagged releases verify the exact MCPB hash during CI and again before publication.

## Compatibility and upgrades

Python 3.11–3.13 remains supported on Windows, macOS, and Linux. Existing clients retain the default
raw point-editing behavior, unlinked accents, and exports without a design gate.

Projects using design specs, references, or linked compositions use manifest schema 3. This version
still opens schemas 1 and 2, but older servers cannot open schema 3. **Back up the entire project folder,
including reference artifacts, before upgrading.** Keep original scans separately.

These tools do not automatically trace drawings or certify visual fidelity, interpolation quality,
or professional typographic quality. The client must inspect the returned images.

## Install or update

With Node.js 20+ and Git:

```sh
npx --yes github:Kydaix/Font-Design-MCP#v0.5.0
```

Restart configured clients after installation. Existing workspaces and client settings are preserved.
GitHub assets include the wheel, source archive, MCPB extension, and `SHA256SUMS`; there is no PyPI or npm
package publication.
