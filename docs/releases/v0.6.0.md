# Font Design MCP 0.6.0

This release makes defects in diagonal strokes, variable weights and incomplete review evidence easier
to detect. It adds persistent stroke constructions and stronger export gates, and includes the Latin
mark export fixes merged since 0.5.0.

## Highlights

- **Regional stroke coverage:** perpendicular width profiles measure taper and counters; separate
  branches and joins need their own spatial samples. A measurement of K's stem cannot validate its arms.
- **Variable font diagnostics:** compiled profiles detect weight reversals at intermediate coordinates.
  Source correspondence checks and a bounded min/mid/max grid detect incompatible or empty instances.
- **Review evidence tied to the output:** `proof_review` and `font_release_check` bind observations to
  source revisions and image hashes. Text evidence also binds to the compiled font hash and requires
  visible, shaped usage at small and large sizes, with and without kerning, for each master.
- **Persistent constructions:** optional `stroke_network` geometry links centerlines to named width
  parameters. Horizontal scaling preserves normal stroke widths; free edits require explicit detachment.
- **Reference provenance:** cropped references preserve the original calibrated page. Difference overlays
  compare ink, while glyph origins distinguish observed forms from extrapolated or original drawings.
- **Focused inspection:** select project sections and glyphs, paginate spacing and composition data,
  and use evidence plans and grouped findings to prepare the next measurements and proofs.
- **Export compatibility:** Latin language-system declarations restore accent positioning in compiled
  fonts. Variable exports populate STAT values and order named instances. Optional binary and browser
  scripts record shaping, TTF/WOFF2 round trips and rendered specimens.

## Compatibility and migration

Python 3.11–3.13 remains supported on Windows, macOS and Linux. The MCP exposes 20 tools, including the
review and release-check tools added since 0.5.0.

Schemas 1–4 remain readable. New regional, usage, variation-profile, provenance, cropped-reference and
stroke-network features use design-state version 3 and **manifest schema 5**, which older servers reject.
**Back up the entire project folder, including referenced artifacts, before upgrading.** Keep original
reference images separately. Using the new features can prevent reopening the edited revision in an
older server; preserved older revisions remain available.

`font_build()` produces an unreviewed proof. `require_design_checks=true` enforces the design contract;
`purpose="release"` also requires complete revision-bound review evidence. Stricter gates can reject
previously accepted, incomplete evidence. This compiler update invalidates cached binaries, so regenerate
text proofs and their reviews before requesting a reviewed font export.

## Validation and limits

Regression tests cover blank or duplicated glyphs, tapered diagonals, regional coverage, weight reversal,
stale or tampered evidence, cropped references, linked constructions and interpolation failures.
The release workflow runs the suite and installer/package checks on three operating systems with
Python 3.11 and 3.13 before publishing the distributions.

Passing checks does not certify artistic perfection, exact reconstruction from a raster reference,
every language sequence or the continuous variation space. The client agent must receive and inspect
the returned images. Review attestations and evidence plans cannot substitute for that inspection.
This software release does not approve any particular typeface as ready for delivery.

## Install or update

With Node.js 20+ and Git:

```sh
npx --yes github:Kydaix/Font-Design-MCP#v0.6.0
```

Restart configured clients after installation. Existing workspaces and client settings are preserved.
GitHub assets include the wheel, source archive, MCPB extension and `SHA256SUMS`; there is no PyPI or npm
package publication.
